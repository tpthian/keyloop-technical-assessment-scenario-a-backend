# ADR-011: Quality gates enforced by the repository

Status: Accepted, 2026-11-03 (D-008)

## Context
Pre-commit hooks are opt-in and bypassable, so alone they enforce nothing for a newcomer.

## Decision
Pre-commit (ruff format and lint, mypy on the app package, gitleaks, whitespace and end-of-file fixers) plus GitHub Actions running the same configuration and pytest on every push. Set up with the repository skeleton, after the design. The README mentions it in one line; the guarantee leads.

## Alternatives rejected
- Hooks only: bypassable.
- Convention and review: does not scale past one author.

## Consequences
Scope guard: no coverage thresholds, release automation or dependency bots.
